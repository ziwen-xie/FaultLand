# 我在末世捡垃圾

一个中文末世生存 Roguelike 可玩原型。纯 HTML、CSS、JavaScript，无构建依赖、无 CDN、无外部图片或账号要求。

## 立即游玩

直接双击 `index.html`，在现代浏览器打开即可。建议使用最新稳定版 Chrome、Edge、Safari 或 Firefox。

也可在已安装 Node.js 的电脑中运行：

```sh
npm start
```

打开 `http://127.0.0.1:4173`。预览服务仅绑定本机，不对局域网开放。

## 手机和电脑同时游玩

手机端会自动切换为专用布局：底部「探索 / 背包 / 手记 / 成就」导航、固定探索操作区、可左右滑动的战斗手牌，以及全屏战斗和安全区域适配。电脑端保持多栏布局，无需切换版本。卡牌下方的手柄支持触摸或鼠标拖动排序；键盘聚焦手柄后可用左右方向键调整。

在电脑项目目录运行：

```sh
npm run mobile
```

手机与电脑连接同一 Wi-Fi，然后在手机浏览器打开终端输出的局域网地址，例如 `http://电脑的局域网IP:4174`。不要在手机上输入 `127.0.0.1`，它会指向手机自身。电脑需要保持服务运行。若系统询问网络访问权限，允许专用网络访问即可；访客 Wi-Fi 的设备隔离也可能阻止访问。

默认 `npm start` 仍只开放本机；`npm run mobile` 使用 4174 端口提供局域网预览，仅提供游戏页面、脚本、样式和本地插画。不同网卡可能显示多个地址，请选择手机所在 Wi-Fi 对应的地址。局域网模式不会生成互联网分享地址。

两端使用相同规则和存档格式，但存档分别保存在各自浏览器中，不会跨设备自动同步。已有存档仍兼容。

存档保存在浏览器本机存储中，包括进行中的战斗。无痕模式、清理浏览器数据或更换打开方式/浏览器可能让存档不可用。直接打开文件时若浏览器禁止本地存储，界面会提示无法保存；使用本地服务可获得更稳定的存档环境。

## 一局的目标

1. 从 B5 避难所出发，选择上下左右相邻区块并移动。
2. 搜寻物资、零件与卡牌，弹窗会逐项显示收获。一个地区可以在物资搜寻后继续触发怪物、商人和选择事件。医院、地铁与部分废墟会展开 3×3 内部地图；走到出口会直接返回大地图。
3. 战斗先选择骰子，再使用满足点数要求的固有卡。每回合有 3 点行动值，可以催发异能生产消耗卡；新卡会立即出现在当前战斗卡牌区。结束回合后，敌方攻击以独立窗口显示攻击、护盾抵消、实际伤害和剩余健康。
4. 第 1、3、5、7、9 次战斗胜利可从四项异变中选择：觉醒新异能，或升级已经拥有且尚未满级的异能。
5. 击败医院、地铁、电厂的守卫，取得三枚核心，再前往 F1 零号信号塔击败最终怪物。

每次移动消耗 3 饱食、4 水分、1 SAN，并恢复 6 精力。搜寻通常消耗 2 饱食、3 水分、1 SAN；裂隙消耗 4 SAN。敌方回合消耗 1 饱食、1 水分并恢复 6 精力。精力全局共享，上限 100。

饱食或饮水降到 20 及以下时会弹出可关闭的补给提醒；归零时升级为生存警报。饱食为 0 时每次行动损失 5 健康，水分为 0 时损失 8 健康，两者可叠加，并逐步形成虚弱 I–III。虚弱 II 会把战斗骰子减为 2 枚，虚弱 III 还会减少行动值，并启动 3 次行动的昏厥死亡倒计时。补回食物和水可以中止倒计时并逐步消除虚弱。

卡牌分为固有卡和消耗卡。固有卡打出后进入弃牌堆并循环洗牌；普通消耗卡用后扣除，耐久卡会在耐久归零时消失。未用卡牌跨回合保留，并可卖给商人或交给事件角色。中毒与燃烧在敌方行动前结算，绿色毒条显示下一次中毒可能侵蚀的生命；燃料需要打火机引燃。幸运扳机和口袋好运可把当前可用骰子增加到最多 6 枚。

## 已实现

- 6×5 随机区块、迷雾揭示、相邻移动、一次性搜寻、固定安全起点。
- 健康、饱食、水分、理智，以及罐头、净水、急救包、零件。
- 首批 100 张不重名卡牌：64 张固有卡与 36 张消耗卡；内容量统计和收集目标为动态值，可继续扩充到 100 张以上。
- 30 项异能，其中 8 项可主动生产消耗卡，24 项拥有多级成长；异能和卡牌均有普通、精良、稀有、史诗、传说五档稀有度。
- 毒蚀、燃烧、蛮力、防御、流血、控制、电能、骰运、生存与精神十种流派；包含绿色毒条、易伤、减速、荆棘、状态转化和耐久卡。
- 卡牌与骰子回合制战斗、敌方意图、防御、治疗、持续伤害、重掷与撤退。
- 工作台制作、异常选择事件、胜负结局、随机种子与自动存档。
- 中文响应式界面，支持鼠标、键盘焦点和移动端触摸。
- 暖纸色生存手记 UI、废墟场景插画、拾荒者与怪物肖像、12 格物品插画和本地 SVG 图标。
- 搜寻收获可点击查看详情，包括持有量、使用效果、骰点要求、背包与工作台入口。嵌套页面返回后仍保留收获弹窗。
- 普通地块搜寻有 40% 概率获得一张卡牌，先按稀有度权重、再在对应档位内抽取；还能找到袋装薯片和浓缩咖啡。搜过的地块变灰并打勾，仍可经过。
- 20 类事件，包括受伤陌生人、流动商人、救助队、瘦狗、镜面集市、无声列车与自动气象站等；多数事件提供三项带成本或风险的选择。
- 救人消耗急救包：可能立即背叛，也可能在之后 2–4 次移动时得到援助或遭遇伏击。未来结果在选择时确定，刷新不会重新抽签。
- 商人随机库存与价格；补给和卡牌均可购买。救助队提供一次免费治疗，或接受口粮捐赠并回赠净水。
- 背包卡组与战斗手牌拖动排序；探索时可分解重复卡，获得 2 零件，保留同名卡至少一张和总卡组至少五张。
- 结算根据救援、制作、冒险、异能、毒蚀、燃烧、战斗和避险行为生成八类特色人格称号；无明显倾向时有默认称号。
- 23 项成就，覆盖探索、生存、战斗、人际与收藏；新增全稀有度收集、传说卡、异能升级和满级成就。新版成就册提供完成度仪表盘与分类筛选。
- 卡牌与异能图鉴提供动态总进度、五档稀有度台账、已收集/未收集筛选、流派或类型筛选和名称/效果搜索；记录跨局保存在本机，不提供局外属性加成。
- 3×3 区域内部地图、房间迷雾、独立搜寻、核心守卫与出口自动返回；刷新会保留内部进度。
- Boss 战利品通知：核心、零件、物资和卡牌逐项列出；医院守卫额外掉落急救包。

## 项目结构与验证

```text
index.html             页面结构；可直接打开
styles.css             生存手记主题、地图、卡牌与各类弹窗
mobile.css             手机导航、触摸布局、全屏战斗与安全区域
icons.js               本地 SVG 图标和物品图集映射
assets/                4 张生成插画及 ART-DIRECTION.md 最终提示词
engine.js              平台无关的规则、随机数与存档验证
content.js             可扩展卡牌、异能与事件数据
app.js                 浏览器 UI、交互与本机存档
server.cjs             可选的本机静态预览服务
tests/engine.test.cjs   规则与进度回归测试
tests/browser-smoke.cjs 可选 Chrome 实际浏览器交互检查
DESIGN.md              玩法设计与小程序迁移边界
CONTENT-CATALOG.md      100 张卡牌、30 项异能、20 类事件完整总表
tools/generate-catalog.cjs  按当前内容数据重新生成总表
```

```sh
npm test
npm run check
npm run catalog
```

`npm test` 包含 36 项规则测试，其中逐张执行全部卡牌、逐项结算扩展事件，遍历 500 个世界种子检查核心据点，并遍历 1500 个种子检查五档卡牌掉落、20 类事件、连续遭遇和收获存档。还覆盖虚弱死亡链、异能升级、新成就进度、持续伤害、耐久卡、精力与行动值、敌方攻击报告、区域出口、Boss 战利品、商人、卡牌排序与旧存档迁移。实际 Chrome 测试覆盖桌面、7 组手机与横屏尺寸、触摸操作、生存警报、成就筛选、图鉴搜索、稀有度与流派筛选；不等同于 iOS/Android 真机验收。

本版本是单人玩法验证原型，包含本地插画，没有联机、云存档或音效。游戏时钟反映行动次数，昼夜目前只作氛围显示，不改变敌人强度。HTML 已可游玩；小程序可复用 `engine.js`，仍需另写平台界面与存储适配。
